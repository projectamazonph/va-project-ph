# Copy Bible - The VA Project Philippines

Version: 1.0 · Reviewed: 2026-08-17 · Owner: Design Lead (voice) + Curriculum (accuracy)

Voice: warm professional. Clear English (clients speak English; we train for that), with Filipino warmth where emotion lives. Never slang in money/career content. Never condescend.

## Voice Rules

| Do | Don't |
|---|---|
| Plain words: "cost per click" before "CPC" | Jargon without a glossary link |
| Verbs on buttons: Start, Continue, Grade, Copy | "Submit", "Click here", "OK" |
| Encourage effort, praise specifics | Generic hype ("You're amazing!") |
| Admit product faults plainly | Corporate fog ("We experienced an issue") |
| Short sentences. One idea each. | Walls of text |
| "You" and "we" | "The user", passive voice |

### Taglish policy (precise)

- English only: lessons, metrics, reports, money, client-facing templates, legal.
- Warm Taglish allowed: greetings, streaks, encouragement toasts, empty states, celebration. Examples below marked with PH flag.
- Never mix within a single sentence in UI copy.

## In-App Copy Library

### Greetings (rotate)

- "Magandang araw, {name}!" (with wave emoji)
- "Welcome back, {name}. Ready for one small win?"
- (morning) "Good morning, {name} - a fresh start."

### Empty states

| Context | Copy | Action |
|---|---|---|
| No lessons done | "Your journey starts with one lesson. Ten minutes. Kaya mo 'yan." | Start Module 1 |
| Trainer untouched | "This is where managers are made. Review a fake report - mistakes here are free." | Try your first review |
| No badges | "Badges show up as you practice. Your first one is one lesson away." | Browse lessons |
| Grading queue empty | "All caught up! New submissions will appear here." | - |
| No students (teacher) | "No students yet. Ask your admin to link your cohort." | Contact admin |

### Loading

- "Loading your progress..."
- "Crunching the numbers..." (reports)
- "Coach is thinking..."
- (Always skeleton + text together; never naked spinners.)

### Errors (plain, blameless, actionable)

| Case | Copy |
|---|---|
| Generic 500 | "Something went wrong on our side. Your progress is safe - please try again." |
| Network | "No connection. We saved your place - you can keep reading, and we'll sync when you're back online." |
| Validation | "Check the highlighted fields and try again." |
| 404 | "We can't find that page. It may have moved. Let's get you back on track." -> Home button |
| Rate limit | "You're moving fast! Take a short breather and try again in a few seconds." |
| Auth expired | "For your safety, please sign in again. Your progress is waiting." |
| Trainer incomplete | "Choose an action for every row first - real managers check everything." |

## Copy QA Gates (CI + review)

- Readability <= grade 8 (automated) for student-facing strings.
- Jargon scanner: any term in glossary list must be linked or accompanied by definition on first use.
- Taglish only in approved zones (§1) - lint checks string namespace.
- No absolutes in outcome claims ("will", "guarantee") - banned-word list.
- Currency: PHP for prices, $ in curriculum examples (Amazon context) - never mixed in one string.
