# Amazon PPC Training Syllabus
## From Zero Knowledge to Competent Virtual Assistant Manager

## Course Goal

To teach absolute beginners how Amazon PPC works, how to manage campaigns safely, and how to become virtual assistants who can support or manage Amazon advertising with confidence.

By the end of this course, a student should be able to:

1. Explain what Amazon PPC is in simple words.
2. Understand the main Amazon ad types.
3. Read and explain common PPC reports.
4. Build basic campaigns.
5. Find keywords.
6. Add negative keywords.
7. Make simple bid and budget changes.
8. Spot problems in a campaign.
9. Follow a safe weekly management routine.
10. Communicate clearly with a client or manager.
11. Use templates, checklists, and dashboards.
12. Avoid costly beginner mistakes.

---

# 1. Student Profile

This course is for:

- Virtual assistants with no Amazon PPC experience.
- Beginners who have never run ads.
- People who want to become junior PPC assistants.
- People who want to manage small Amazon ad accounts.
- Students who need practical work, not only theory.

No prior marketing knowledge is required.

---

# 2. Teaching Philosophy

Use these rules when teaching:

| Rule | Meaning |
|---|---|
| Start with zero | Assume the student knows nothing. |
| Use plain words | Avoid jargon until it is explained. |
| Show before telling | Show a real screen or example first. |
| Repeat key ideas | PPC has many small terms that need repetition. |
| Use small tasks | Break every job into tiny steps. |
| Use checklists | VAs need repeatable systems. |
| Practice safely | Use sandbox data before live accounts. |
| Teach judgment | Do not only teach buttons. Teach why. |

## Module 0: Amazon Basics Before PPC

### Goal

Understand what Amazon is, what a product page is, and why ads matter.

### Lessons

1. What is Amazon Marketplace?
2. What is a seller account?
3. What is a product listing?
4. What is the Buy Box?
5. What is organic rank?
6. What is paid rank?
7. Why do sellers use ads?

### Simple Explanation

Amazon is like a giant online store. When a customer searches for a product, Amazon shows many results. Some results are natural, or "organic." Some results are paid ads. PPC helps a product appear in front of shoppers faster.

### Key Terms

| Term | Simple Meaning |
|---|---|
| Product listing | The page where the product is sold |
| Organic result | Free result earned by relevance and sales |
| Paid result | Result shown because seller pays for ads |
| Buy Box | The main "Add to Cart" area |
| Rank | Where a product appears in search results |
| Conversion | When a visitor buys |

### Example

Imagine a customer searches:

`bamboo cutting board`

Amazon shows:

- Some organic products.
- Some sponsored products.
- Some brand ads.

A seller can pay to appear near the top using Amazon PPC.

```text
[ Sponsored Product ]

[ Organic Result ]

```

### Activity

3. Why would a seller use PPC?

## Module 1: What is Amazon PPC?

### Goal

Learn the basic idea of pay-per-click advertising on Amazon.

### Lessons

1. What does PPC mean?
2. How does Amazon decide which ads to show?
3. What is an auction?
4. What is a bid?
5. What is a click?
6. What is an impression?
7. What is a sale?

### Simple Explanation

PPC means "Pay Per Click." The seller does not pay just to show the ad. The seller pays when a shopper clicks the ad.

Amazon PPC works like an auction. Sellers bid money for a chance to show their ad. If a shopper clicks, the seller pays.

### Key Terms

| Term | Simple Meaning |
|---|---|
| Impression | Ad was shown |
| Click | Shopper clicked the ad |
| Bid | The amount seller is willing to pay |
| CPC | Cost per click |
| Auction | Sellers compete for ad placement |
| Ad placement | Where the ad appears |

### Example

A seller sells a bamboo cutting board.

- Seller bids $1.00 per click.
- Shopper searches "bamboo cutting board."
- Amazon shows the seller's ad.
- Shopper clicks the ad.
- Seller pays about $1.00.

If the shopper buys, the ad made a sale.

### Diagram: PPC Flow

```text
Customer searches
       |
       v
Amazon auction begins
       |
       v
Sellers bid for ad space
       |
       v
Amazon chooses ads to show
       |
       v
Customer sees ad
       |
       v
Customer clicks ad
       |
       v
Seller pays click cost
       |
       v
Customer may buy
```

### Activity

Student explains:

1. What does PPC stand for?
2. When does the seller pay?
3. What is a bid?
4. What is the difference between impression and click?

### Deliverable

- Simple drawing or written flow of a PPC click.

## Module 2: Money Math Every PPC Assistant Must Know

### Goal

Understand the numbers used to judge ad performance.

This is one of the most important modules. Do not rush it.

### Lessons

1. Spend
2. Sales
3. Clicks
4. Impressions
5. CPC
6. CTR
7. Conversion rate
8. ACOS
9. ROAS
10. TACoS
11. Break-even ACOS
12. Profit margin

### Core Metrics Table

| Metric | Simple Meaning | Formula |
|---|---|---|
| Impressions | Number of times ad was shown | Count from report |
| Clicks | Number of ad clicks | Count from report |
| Spend | Money spent on ads | Total cost |
| Sales | Money made from ads | Total attributed sales |
| CPC | Average cost per click | Spend / Clicks |
| CTR | Click-through rate | Clicks / Impressions |
| Conversion Rate | Percentage of clicks that became sales | Orders / Clicks |
| ACOS | Ad cost as percent of ad sales | Spend / Sales x 100 |
| ROAS | Return on ad spend | Sales / Spend |
| TACoS | Total ad cost compared to total revenue | Ad Spend / Total Revenue x 100 |
| Break-even ACOS | Highest ACOS before losing money | Profit margin percentage |

### Plain-Word Meaning

- Spend: "How much we paid for ads."
- Sales: "How much money the ads helped bring in."
- CPC: "How much one click costs on average."
- CTR: "Out of all the people who saw the ad, how many clicked?"
- Conversion Rate: "Out of all the clicks, how many bought?"
- ACOS: "How much of the ad sales went to paying for ads."
- ROAS: "How many dollars came back for every ad dollar spent."
- Break-even ACOS: "The highest ACOS we can have before losing money."

### Example 1: Simple ACOS

A campaign has:

- Spend: $20
- Ad sales: $100

ACOS = $20 / $100 = 20%

Meaning: For every $1 in ad sales, $0.20 was spent on ads.

### Example 2: Break-even ACOS

Product price: $25
Product profit after costs: $7.50
Profit margin: 30%

Break-even ACOS = 30%

If ACOS is below 30%, the ads may be profitable.
If ACOS is above 30%, the ads may lose money.

### Example 3: CPC and Conversion Rate

Product price: $25
Average CPC: $1.00
Conversion rate: 10%

This means 10 clicks produce 1 sale.

Cost to get 1 sale:

10 clicks x $1.00 = $10

If the product makes $7.50 profit, the ad may lose money.

### Money Math Practice Table

| Spend | Sales | ACOS | Good or Bad? |
|---:|---:|---:|---|
| $10 | $100 | 10% | Usually good |
| $25 | $100 | 25% | Depends on margin |
| $40 | $100 | 40% | May be bad if margin is 30% |
| $100 | $0 | No sales | Problem |

### Activity

Student calculates:

1. Spend $15, sales $60. What is ACOS?
2. Spend $50, sales $250. What is ROAS?
3. Product margin is 35%. Campaign ACOS is 42%. Is this likely profitable?
4. CPC is $0.80. Conversion rate is 5%. What is cost per sale?

### Deliverable

- PPC math worksheet completed correctly.

## Module 3: Campaign Structure

### Goal

Understand how Amazon PPC accounts are organized.

### Lessons

1. Campaigns
2. Ad groups
3. Targeting
4. Bids
5. Budgets
6. Placements
7. Products inside ad groups

### Simple Explanation

Amazon PPC is organized like folders.

```text
Campaign
   |
   +-- Ad Group
          |
          +-- Product
          |
          +-- Targeting
```

A campaign controls the budget.
An ad group contains products and targeting.
Targeting tells Amazon when to show the ad.

### Diagram: Campaign Structure

```text
Campaign: Bamboo Cutting Board - Auto
Budget: $20/day
        |
        v
Ad Group 1: Main Product
        |
        +-- Product: Bamboo Cutting Board
        |
        +-- Targeting: Automatic
```

```text
Campaign: Bamboo Cutting Board - Manual Keywords
Budget: $25/day
        |
        v
Ad Group 1: Kitchen Keywords
        |
        +-- Product: Bamboo Cutting Board
        |
        +-- Keywords:
              bamboo cutting board
              cutting board for kitchen
              large bamboo chopping board
```

### Campaign Types

| Campaign Type | Simple Meaning | Best For |
|---|---|---|
| Sponsored Products | Ads for one product | Most beginners |
| Sponsored Brands | Ads for a brand with logo | Brand-registered sellers |
| Sponsored Display | Ads on and off Amazon | Retargeting and awareness |

For absolute beginners, start with Sponsored Products.

## Module 4: Keywords and Match Types

### Goal

Learn what keywords are and how Amazon matches ads to shopper searches.

### Lessons

1. What is a keyword?
2. What is a search term?
3. Difference between keyword and search term
4. Broad match
5. Phrase match
6. Exact match
7. Negative keywords

### Simple Explanation

A keyword is the word or phrase the seller chooses.
A search term is what the customer actually types.

Example:

Seller keyword: `bamboo cutting board`

Customer search terms may be:

- bamboo cutting board
- large bamboo cutting board
- bamboo cutting board for vegetables
- cheap bamboo cutting board

### Match Types

| Match Type | What It Means | Control | Reach |
|---|---|---:|---:|
| Broad | Shows for related searches | Low | High |
| Phrase | Shows for searches containing the phrase | Medium | Medium |
| Exact | Shows for very close matches | High | Low |
| Negative | Tells Amazon not to show for certain words | High | Prevents waste |

### Example

Keyword: `bamboo cutting board`

| Match Type | May Show For | May Not Show For |
|---|---|---|
| Broad | bamboo chopping board, cutting board | plastic cutting board if not relevant |
| Phrase | large bamboo cutting board | bamboo board for crafts |
| Exact | bamboo cutting board | bamboo cutting board set |

### Negative Keywords

Negative keywords stop ads from showing for unwanted searches.

Example negative words:

- glass
- plastic
- knife set
- cheap
- wholesale
- bulk
- free

### Example Use Case

A seller sells premium bamboo cutting boards.

The ad keeps getting clicks for:

- plastic cutting board
- glass cutting board
- cutting board with knife set

These clicks are wasted.

Solution:

Add negative keywords:

```text
plastic
glass
knife set
```

### Activity

Student is given 20 search terms and must label them:

- Good
- Bad
- Add as keyword
- Add as negative
- Need more data

### Deliverable

- Keyword and negative keyword worksheet.

## Module 6: Campaign Setup for Beginners

5. Choosing products for ads
6. Naming campaigns

### Campaign Types for Beginners

| Campaign | What It Does | Why Use It |
|---|---|---|
| Auto Campaign | Amazon chooses targeting | Finds search terms |
| Manual Keyword Campaign | Seller chooses keywords | Controls targeting |
| Manual Product Targeting Campaign | Targets specific products or categories | Competitor or related product ads |

### Recommended Beginner Structure

For a new product, start simple.

```text
Campaign 1: Auto Research
Purpose: Find search terms

Campaign 2: Manual Exact Keywords
Purpose: Control best keywords

Campaign 3: Manual Product Targeting
Purpose: Target related or competitor products
```

### Example Setup

Product: Bamboo Cutting Board
Price: $24.99
Margin: 30%
Daily budget: $20

```text
Campaign 1: SP - Auto - Bamboo Cutting Board
Budget: $10/day
Bids: Low to medium

Campaign 2: SP - Manual Exact - Bamboo Cutting Board
Budget: $10/day
Keywords:
- bamboo cutting board
- bamboo chopping board
- large bamboo cutting board
```

### Naming Convention

Use clear names.

Example:

```text
SP | Auto | Bamboo Cutting Board | Research
SP | Exact | Bamboo Cutting Board | Kitchen Keywords
SP | Product Targeting | Bamboo Cutting Board | Competitors
```

## Module 7: Bids and Budgets

### Goal

Learn how to set bids and budgets without wasting money.

### Lessons

1. What is a daily budget?
2. What is a bid?
3. How budget and bid work together
4. Low budget strategy
5. High bid vs low bid
6. Bid rules
7. When to raise bids
8. When to lower bids

### Simple Explanation

Budget is the daily limit.
Bid is how much you are willing to pay for a click.

Example:

- Daily budget: $20
- Average CPC: $1.00

The campaign may get about 20 clicks per day.

### Budget Table

| Daily Budget | Average CPC | Estimated Clicks |
|---:|---:|---:|
| $10 | $0.50 | 20 |
| $10 | $1.00 | 10 |
| $20 | $1.00 | 20 |
| $50 | $1.25 | 40 |

### Bid Rules for Beginners

| Situation | Action |
|---|---|
| No impressions | Bid may be too low or listing not relevant |
| Many clicks, no sales | Check listing, price, keyword intent |
| Good sales, low ACOS | May raise bid carefully |
| High ACOS, low profit | Lower bid or add negatives |
| Budget ends too early | Increase budget or lower bids |
| Campaign not spending | Increase bid or improve relevance |

### Example Use Case

Campaign data:

- Spend: $30
- Sales: $120
- ACOS: 25%
- Margin: 30%

This campaign may be profitable.

Possible action:

- Increase bids slightly on converting keywords.
- Watch for 7 days.

### Activity

Student reviews five campaigns and recommends:

- Raise bid
- Lower bid
- Pause keyword
- Add negative
- Do nothing

## Module 8: Search Term Mining and Negative Keywords

### Goal

Learn how to use search term reports to improve campaigns.

### Lessons

1. What is a search term report?
2. How to read search terms
3. How to find winners
4. How to find wasters
5. How to add negatives
6. How to move winning search terms to exact match

### Simple Explanation

Search terms show what customers actually typed. Some are good. Some waste money. The manager's job is to keep the good ones and block the bad ones.

### Search Term Review Table

| Search Term | Clicks | Sales | ACOS | Decision |
|---|---:|---:|---:|---|
| bamboo cutting board | 12 | 4 | 18% | Move to exact |
| bamboo cutting board large | 8 | 2 | 22% | Test exact |
| plastic cutting board | 10 | 0 | No sales | Negative |
| cutting board with knife set | 7 | 0 | No sales | Negative |
| wooden cutting board | 15 | 1 | 60% | Review bid/listing |

### Decision Rules

| Condition | Action |
|---|---|
| High clicks, no sales | Add negative or pause |
| Good sales, low ACOS | Add to exact match |
| Good sales, high ACOS | Lower bid |
| Irrelevant search term | Add negative |
| Relevant but weak | Watch and collect more data |

### Example Use Case

A campaign has 50 clicks and no sales for:

```text
glass cutting board
```

The product is bamboo, not glass.

Action:

Add `glass` as negative keyword.

3. Recommend negatives.

## Module 9: Weekly Optimization Routine

### Goal

Teach the VA a safe weekly management process.

### Lessons

1. Weekly PPC checkup
2. What to check first
3. What not to touch too often
4. How to make one change at a time
5. How to document changes

### Weekly Routine

| Day | Task |
|---|---|
| Monday | Check spend, budget, and urgent issues |
| Tuesday | Review search terms |
| Wednesday | Add negatives and move winners |
| Thursday | Review bids and ACOS |
| Friday | Prepare simple report |

### Weekly Optimization Loop

```text
Collect data
     |
     v
Find problems
     |
     v
Choose one action
     |
     v
Make small change
     |
     v
Wait and observe
     |
     v
Record result
```

### Optimization Rules

| Problem | Possible Cause | Action |
|---|---|---|
| Low impressions | Low bid, low budget, weak relevance | Check bid and budget |
| High clicks, no sales | Weak listing, wrong keyword, high price | Check listing and search intent |
| High ACOS | CPC too high, low conversion | Lower bid or pause poor targets |
| Low CTR | Weak image, price, title | Check main image and price |
| Budget gone too fast | Budget too low or bids too high | Adjust budget or bids |
| No sales at all | Listing or targeting issue | Stop and review basics |

### Important Rule for Beginners

Do not make many changes at once.

Good:

- Change one bid.
- Add one negative.
- Pause one bad keyword.

Bad:

- Changing 50 bids.
- Pausing everything after one bad day.
- Making decisions from one day of data.

### Activity

Student completes a weekly optimization checklist.

### Deliverable

- Weekly PPC checklist filled out for a practice account.

## Module 10: Reporting and Explaining Results

### Goal

Teach VAs how to create simple reports that humans can understand.

### Lessons

1. Why reports matter
2. What to include
3. What to leave out
4. How to explain changes
5. How to write a simple summary

### Simple Report Structure

| Section | What to Say |
|---|---|
| Spend | How much was spent |
| Sales | How much ad sales were made |
| ACOS | Cost as percent of sales |
| Clicks | How many clicks |
| Conversion Rate | How many clicks became sales |
| Wins | What worked |
| Problems | What did not work |
| Next Steps | What will be done next |

### Example Report

```text
Weekly PPC Report

Spend: $210
Ad Sales: $950
ACOS: 22%
Clicks: 180
Orders: 19
Conversion Rate: 10.5%

What worked:
- Exact match keyword "bamboo cutting board" produced sales.
- Auto campaign found new search term "large bamboo chopping board."

Problems:
- "plastic cutting board" got clicks but no sales.
- One competitor ASIN target had high CPC and no sales.

Next steps:
- Add "plastic" as negative keyword.
- Move "large bamboo chopping board" to exact match.
- Lower bid on poor ASIN target.
```

### Reporting Rules

| Rule | Why |
|---|---|
| Use simple words | Client may not know PPC terms |
| Show trend | Compare to last week |
| Explain action | Numbers alone are not enough |
| Do not hide problems | Trust matters |
| Keep report short | Busy people need clear summaries |

## Module 11: Troubleshooting Common Problems

### Troubleshooting Table

| Problem | First Check | Second Check | Possible Fix |
|---|---|---|---|

Checks:

1. Is product in stock?

## Use Case 1: New Product With No Reviews

Product: Bamboo cutting board
Problem: New listing, no reviews, limited budget.

Strategy:

- Start with small budget.
- Use auto campaign for research.
- Use exact match long-tail keywords.
- Avoid broad expensive keywords.
- Focus on relevant searches.

```text
organic bamboo cutting board
```

Budget:


## Use Case 2: High ACOS Campaign

Campaign data:

- Spend: $80
- Sales: $160
- ACOS: 50%
- Margin: 30%

Problem:

The campaign is likely losing money.

Possible actions:

1. Review search terms.
2. Add negatives for irrelevant clicks.
3. Lower bids on expensive keywords.
4. Pause keywords with many clicks and no sales.
5. Check product listing.

Do not:

- Pause everything immediately.
- Make 20 changes at once.
- Judge from one day only.

## Use Case 3: Good Campaign With Low Impressions

Campaign data:

- Impressions: 200
- Clicks: 8
- Sales: 3
- ACOS: 15%

Problem:

The campaign works but is not showing enough.

Possible actions:

1. Raise bid slightly.
2. Increase budget if profitable.
3. Add more related exact keywords.
4. Check if budget runs out too fast.

## Use Case 4: Product Out of Stock

Problem:

Product is out of stock but ads are still running.

Risk:

Money may be wasted.

Action:

- Pause ads or reduce budget.
- Notify manager or client.
- Restart when stock returns.

# 11. How to Train Virtual Assistants to Become Managers

This section is the bridge from "learning PPC" to "doing the job."

## Stage 1: Watch and Learn

VA watches trainer manage a real or practice account.

VA tasks:

- Take notes.
- Define terms.
- Identify what changed.
- Write why the change was made.

## Stage 2: Prepare Data

VA learns to collect information.

VA tasks:

- Download reports.
- Copy search terms into sheet.
- Sort by spend, clicks, sales.
- Mark obvious winners and wasters.

## Stage 3: Make Safe Recommendations

VA does not change live campaigns yet.

VA tasks:

- Suggest negatives.
- Suggest bid changes.
- Suggest keywords.
- Explain reasoning.

Trainer reviews every recommendation.

## Stage 4: Make Approved Changes

VA makes changes only after approval.

Allowed changes:

- Add negative keywords.
- Pause bad search terms.
- Move winning search terms to exact.
- Make small bid changes.

Not allowed yet:

- Large budget changes.
- Deleting campaigns.
- Changing campaign structure.
- Making major strategy changes.

## Stage 5: Manage Small Accounts

VA manages a small account with supervision.

VA duties:

- Weekly search term review.
- Weekly report.
- Bid suggestions.
- Budget alerts.
- Listing issue alerts.

## Stage 6: Manage with Manager Review

VA manages routine work.

Manager reviews:

- Strategy.
- Big bid changes.
- Budget changes.
- Client communication.
- Monthly performance.

# 12. SOP Library for VAs

These should become standard operating procedures.

## SOP 1: Download Search Term Report

Steps:

1. Open advertising dashboard.
2. Choose date range.
3. Download search term report.
4. Save with date.
5. Upload to folder.
6. Mark review complete.

## SOP 2: Add Negative Keywords

Steps:

1. Open search term report.
2. Filter for high clicks, no sales.
3. Check if search term is relevant.
4. If irrelevant, mark as negative.
5. Choose match type.
6. Save and document.

## SOP 3: Move Winning Search Term to Exact

Steps:

1. Find search term with sales.
2. Check ACOS and margin.
3. Add to manual exact campaign.
4. Set starting bid.
5. Monitor for 7-14 days.

## SOP 4: Weekly Report

Steps:

1. Pull spend, sales, ACOS.
2. Compare to last week.
3. List top keywords.
4. List wasted search terms.
5. List actions taken.
6. List next steps.

## SOP 5: Budget Alert

Steps:

1. Check campaigns running out of budget.
2. Check if campaign is profitable.
3. If profitable, suggest budget increase.
4. If not profitable, suggest review.
5. Notify manager.

# 13. Common Beginner Mistakes to Teach Against

| Mistake | Why It Is Bad | Better Habit |
|---|---|---|
| Changing too many things at once | Cannot tell what worked | Make one change at a time |
| Judging after one day | Data is too small | Wait for enough clicks and time |
| Ignoring search terms | Wasted spend continues | Review weekly |
| Running ads to weak listing | Clicks do not convert | Fix listing first |
| Using only broad match | Can waste budget | Use exact match for control |
| No negative keywords | Ads show for wrong searches | Add negatives regularly |
| Focusing only on ACOS | May miss profit and growth | Look at sales, margin, and goals |
| No notes | Cannot track decisions | Keep change log |
| Making changes without approval | Causes mistakes | Follow VA permission levels |
| Reporting numbers without explanation | Client does not understand | Add simple next steps |

# 16. Safety Rules for the App

Because PPC involves money, the app must teach safe behavior.

## App Safety Rules

| Rule | Implementation |
|---|---|
| No live changes for beginners | Sandbox first |
| Approval required for big changes | Teacher approval workflow |
| Warn when data is too small | Show warning message |
| Warn when action is risky | Highlight risky choices |
| Keep change log | Record every decision |
| Teach documentation | Require notes |
| Prevent overconfidence | Use levels and reviews |
